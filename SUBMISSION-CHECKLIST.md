## Local Impact: what to submit on the IBM platform

The Team Lead submits these four things:

- [ ] **1. Written problem and solution statements:** who has the problem, the problem in their words, and what you built
- [ ] **2. How you used IBM and/or Google technologies:** name each tool and what it does in your app
- [ ] **3. GitHub repo URL**, preferably in the [A2Tech360 GitHub org](https://github.com/A2Tech360) (so [Baz](docs/baz-code-review.md) reviews your PRs)
- [ ] **4. URL to a 1-minute video** of your recorded demo (YouTube, Loom, Google Drive, etc., viewable by anyone with the link)

## Presentations: 5 minutes

- **3–4 minutes presenting:** the person you built for, the problem, your solution, how IBM and/or Google power it, and why it matters for Michigan
- **1–2 minutes of video demo**
- At least one teammate must be present

- [ ] **Public GitHub repo** link
- [ ] **At least 40% of the code is Jac** (judges check)
- [ ] All code written during hacking hours (Sat 12:00 PM to Sun 12:00 PM). Commit early and often; commit history is reviewed.
- [ ] **Demo video:** your 1-minute recorded demo
- [ ] **Project description:** the problem, who it's for, what you built, and **how you used Jac**
- [ ] **Track selection:** pick every track that fits (Agentic AI, Dev Tools & Full-Stack, Local Impact, plus Jac and sponsor awards)
- [ ] **Hosted on JacHammer** ([jachammer.ai](https://jachammer.ai), free sandbox) so judges can try it
- [ ] **Starred** [github.com/jaseci-labs/jac](https://github.com/jaseci-labs/jac)
- [ ] One project per team
- [ ] Repo lives in the [A2Tech360 GitHub org](https://github.com/A2Tech360) and you've opened pull requests so **Baz** reviewed your code ([guide](docs/baz-code-review.md)); required for Local Impact

## Going for a sponsor award?

- [ ] **Best of IBM:** name the IBM tools you used (watsonx.ai, Granite, Orchestrate, Bob, Cloudant, Code Engine) and what each does in your app
- [ ] **Best of Google:** name the Google Cloud services you used (Gemini on Vertex AI, Cloud Run, Firestore, etc.)
- [ ] **Local Impact:** include the completed [problem-discovery worksheet](tracks/local-impact.md#problem-discovery-worksheet) and say who you talked to

## What judges look for

1. **Technical execution:** code quality, architecture, demo stability
2. **Use of Jac and Jaseci:** depth of use (by llm(), walkers, graph modeling)
3. **Creativity and innovation**
4. **Presentation and demo:** a clear, engaging 5-minute presentation
5. **Impact and novelty:** real-world relevance
6. **Depth of agentic behavior:** planning, memory, tool use, multi-agent coordination

Working demos beat slide decks.
